# Spring AI 활용 실습 예제 모듈

| 차시 | 모듈 | 예제 내용 |
| --- | --- | --- |
| 02. Spring AI | `2-chat-client` | 개발 환경 설정 및 `ChatModel`, `ChatClient`를 이용한 AI 모델 연동 |
| 03. Chat 옵션 | `3-chat-options` | 모델과 응답 옵션을 설정하여 AI 응답 제어 |
| 04. Context | `4-chat-memory` | Chat Memory를 활용한 대화 문맥 유지 |
| 05. 멀티모달 입력 ① | `5-multi-modal-image` | 대화 요청에 이미지를 포함하는 멀티모달 입력 |
| 06. 멀티모달 입력 ② | `6-multi-modal-audio` | 대화 요청에 오디오를 포함하는 멀티모달 입출력 |
| 07. RAG | `7-rag` | 문서와 벡터 저장소를 활용한 지식형 챗봇 구현 |
| 08. Tool 기능 | `8-tool` | AI가 애플리케이션의 도구를 호출하도록 기능 확장 |
| 09. Structured Output | `9-structured-output` | AI 응답을 Java 객체 등 구조화된 데이터로 변환 |
| 10. AI 이미지 생성 | `10-image` | 이미지 모델을 활용한 이미지 생성 및 편집 |
| 11. AI 특화 모델 | `11-special` | STT, TTS, Moderation 등 특화 모델 활용 |
| 12. Streaming | `12-stream` | 토큰 스트리밍 기반의 실시간 AI 챗봇 구현 |
| 13. MCP ① | `13-mcp-server-streamable` | Streamable HTTP 방식의 MCP 서버 구현 |
| 13. MCP ① | `13-mcp-server-stdio` | 표준 입출력(STDIO) 방식의 MCP 서버 구현 |
| 14. MCP ② | `14-mcp-client` | MCP 서버와 연결하는 MCP 클라이언트 구현 |
| 15. 로컬 LLM | `15-ollama` | Ollama를 이용한 로컬 LLM 연동 |
