기존 Spring Boot 프로젝트에 간단한 웹 기반 챗 클라이언트를 구현해 줘.

`src/main/resources/static/index.html` 하나로 만들고, Tailwind CSS과 순수 JavaScript를 사용해 줘.

화면은 두 가지 상태로 구성한다.

1. 시작 화면

* 사용자 아이디 입력
* 대화 시작 버튼
* 버튼을 누르면 대화 화면으로 전환

2. 대화 화면

* 상단에 사용자 아이디와 나가기 버튼 표시
* 사용자와 AI 메시지를 말풍선 형태로 표시
* 하단에 메시지 입력창과 전송 버튼 배치
* 전송 시 기존 `POST /chats` 호출
* 나가기 시 `DELETE /chats` 호출 후 시작 화면으로 이동

API 요청과 응답 형식은 프로젝트의 기존 `ApiController` 메서드 시그니처를 확인하여 맞춰 줘.

전체 UI는 최대한 간단하고 깔끔하게 만들고, 불필요한 라이브러리나 복잡한 구조는 사용하지 마.
